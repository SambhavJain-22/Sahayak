Under the Hood

How the bot works

A lightweight RAG pipeline keeps responses accurate and prevents hallucination.

1

Message arrives via WhatsApp

The user sends a text message. A FastAPI webhook receives it and queues a background task.

2

Intent check (first message)

The LLM checks whether the message is about Ayushman Bharat. Off-topic queries receive a polite redirect.

3

Semantic search over the knowledge base

The message is embedded and cosine-similarity matched against paragraphs from the official scheme guidelines.

4

LLM generates a grounded reply

The model answers only from the retrieved text. If the answer isn't there, it refers the user to the official helpline.

5

Reply sent back via WhatsApp Cloud API

The formatted response (and an intro video on first contact) is sent via the Meta WhatsApp Business Cloud API.

Privacy Policy

Only the text messages you send to the bot, your WhatsApp phone number (supplied automatically by the WhatsApp Cloud API so we can reply to you), and the timestamps of those messages.
